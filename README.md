
# Pressure Points — The Weight You Cannot See

An interactive frontend experience exploring the invisible pressures students carry behind everyday smiles, academic expectations, deadlines, and the pressure to appear fine.

🌐 **[View Live Project](https://pressure-points.vercel.app/)**

## 📌 About the Project

**Pressure Points** is a creative frontend project built around the theme of student pressure and concealed cognitive load.

It presents the emotional side of student life through bold typography, minimal layouts, subtle visual details, and an editorial-style interface.

The goal is to make an often invisible experience feel visible through thoughtful design and an engaging web experience.

## ✨ Highlights

- 🎨 Minimal, editorial-inspired visual design
- 🖋️ Bold typography with contrasting accent colors
- 🧠 Student pressure and mental load as the central theme
- 🧩 Structured visual storytelling through exhibit-style sections
- 🔊 Sound toggle interface
- 🌬️ A “Take a Breath” experience element
- 📱 Designed as a modern web experience

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/harxitsingh/pressure-points.git
```

### 2. Navigate to the project folder

```bash
cd pressure-points
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

> These commands assume the project uses a Node.js-based frontend setup. Check `package.json` for the correct commands if your setup differs.

## 🎯 Project Purpose

This project explores how frontend design can communicate an emotional message—not just display information.

It combines visual hierarchy, typography, whitespace, and storytelling to create a digital experience around the pressures students often keep to themselves.
